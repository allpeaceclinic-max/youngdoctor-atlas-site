# 메모 한 통 — 빈 양식

메신저 「나에게 보내기」 한 통은 200자가 상한입니다. 아래 다섯 덩어리만 넣습니다.

```
📖 오늘 본문 __/__(_)
책 __:__-__
「제목 한 줄」

① 하나님은 어떤 분이신가?
② 나는 어떻게 해야 할까?

본문 보기: (본문·해설을 읽을 곳의 주소)
```

## 넣지 않는 것

- 해설 글 — 저작권이 있습니다. 해설은 링크로 읽습니다.
- 본문 여러 절의 원문 — 역본에도 저작권이 있습니다. 장·절 범위만 적습니다.
- 지어낸 적용 — 묵상은 사람이 합니다.

## 모임 전날 저녁판

- 머리줄: `📖 내일 모임 본문 __/__(_)`
- 끝에 한 줄: `(해설은 다음 날 날짜로 넘겨서 보세요)`

## 샘플 (가공 — 102자)

```
📖 오늘 본문 11/4(수)
시편 23:1-6
「(가공 제목) 아침의 한 줄」

① 하나님은 어떤 분이신가?
② 나는 어떻게 해야 할까?

본문 보기: example.org/today
```

글자 수를 세어 200자 안인지 확인합니다. 같은 장 안이면 범위는 「책 3:1-12」처럼 끝 절 번호만 남겨 짧게 씁니다.
