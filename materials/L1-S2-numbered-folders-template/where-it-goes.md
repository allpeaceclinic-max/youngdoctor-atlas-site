# 이런 파일은 이 번호로 — 한 장 양식

새 파일이 어디로 가는지 한 장에 적어 둡니다. 위 다섯 줄은 예시로 채워 두었습니다. 내 일에 맞게 고치고, 활동 영역(01~03) 줄을 더합니다.

| 이런 파일 | 이 자리 |
|---|---|
| 새로 받았는데 어디 둘지 모르겠다 | `00_받은함` |
| 문서·회의 기록·옛 자료 | `05_기록` |
| 양식·템플릿·프롬프트 | `06_도구` |
| 다 만든 영상·음원·발행물 (완성본만) | `07_창작` |
| 해 보는 중인 것 | `08_실험` |
| (내 일 1에 속하는 것) | `01_` |
| (내 일 2에 속하는 것) | `02_` |
| (내 일 3에 속하는 것) | `03_` |

점검:

- [ ] 애매한 것은 받은함으로 보낸다고 적었다.
- [ ] 만든 영상·음원을 그것을 만든 도구 폴더 안에 두지 않는다.
- [ ] 기록과 영상 본체를 다른 자리에 둔다.
- [ ] 큰 갈래가 일곱 개를 넘지 않는다.
