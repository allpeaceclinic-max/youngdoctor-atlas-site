# 세 줄 소개문 카드

> 지금 쓰는 채팅창 맨 앞에 붙이는 세 줄입니다. 두세 줄이면 충분하고, 처음부터 완성하지 않아도 됩니다.

## 1. 세 줄

```text
나는 ______ 이다.
______ 에서 일한다.
답은 ______ 로 해 달라.
```

| 줄 | 적는 것 | 막히면 |
|---|---|---|
| 역할 | 내가 하는 일 | 「나는 ______ 이다」 한 줄만 |
| 환경 | 어떤 컴퓨터 · 어떤 일터에서 일하는지 | 쓰는 컴퓨터 하나만 |
| 말투 | 존댓말 · 한국어 · 핵심부터 등 | 호칭 · 어미 · 리듬 · 정서 가운데 하나만 |

가공 예시(가공 인물):

```text
나는 중학교 과학 교사다.
학교 컴퓨터와 집 노트북에서 일한다.
답은 존댓말로, 핵심부터 짧게 해 달라.
```

## 2. 붙여넣기 전 확인

- [ ] 환자 정보가 없다
- [ ] 실명 개인정보가 없다
- [ ] 인증 키 같은 비밀값이 없다

잘 모르겠으면 넣지 않습니다. 첫 자물쇠는 붙여넣기 전의 내 손입니다.

## 3. before / after 기록

| | before (세 줄 없이, 새 대화) | after (세 줄 + 같은 질문, 새 대화 하나 더) |
|---|---|---|
| 질문 | | (before와 같은 질문) |
| 답 요약 한 줄 | | |
| 달라진 것 하나 (호칭 · 길이 · 말투 · 전제) | | |

## 4. 다음 칸에서

새 대화를 열면 붙여 둔 세 줄은 사라집니다. 다음 칸에서는 이 세 줄을 양식 한 장(나는 누구 · 원칙 · 금지 · 말투)으로 늘려 파일로 만들고, 비밀값은 그 파일 밖에 둡니다.
