# 밑줄 옮기기 지시문 카드

제작자가 책 사진을 옮길 때 쓰는 규칙을, 브라우저의 AI 대화창에 붙이기 좋게 줄인 것입니다. 사진 한 장과 함께 보냅니다.

## 1. 기본 — 그대로 복사

```text
밑줄·동그라미·형광펜 친 부분만 원문 그대로 옮겨 주세요. 요약하지 말고, 표시 안 된 문장은 빼고, 못 읽는 글자는 [?]로 표시하고, 페이지 번호가 보이면 같이 적어 주세요. 제 책에 제가 그은 밑줄을 제 노트로 옮기는 일입니다.
```

마지막 문장은 빼지 않습니다. 책 주인이 자기 밑줄을 자기 노트로 옮기는 일이라는 전제가 없으면, AI가 원문 대신 요약이나 위치 목록만 돌려준 일이 있었습니다.

## 2. 덧붙이고 싶을 때

필요한 줄만 1번 지시문 뒤에 붙입니다.

```text
표시된 문장은 중간에 끊지 말고 끝까지 적어 주세요.
동그라미나 네모를 친 낱말은 굵게 표시해 주세요.
여백에 손으로 쓴 메모는 줄 앞에 📝를 붙여 주세요.
표시가 없는 페이지는 「표시 없음」 한 줄만 적어 주세요.
아예 읽을 수 없는 곳은 […]로 남겨 주세요.
```

## 3. 요약이 돌아왔을 때

```text
요약하지 말고, 표시한 문장은 길어도 끝까지 원문 그대로 전부 적어 주세요. 밑줄이 10개면 10개 다 적어 주세요.
```

## 4. 대조 체크 — 사진을 지우기 전에

- [ ] 사진이 남아 있는 동안 책과 한 번 대조했다
- [ ] 틀린 글자 ___개 · `[?]` ___개
- [ ] 마침표·물음표·닫는따옴표로 끝나지 않는 줄은 사진과 다시 봤다 (대개 페이지 끝 이어짐·낱말 강조·줄 끝에서 끊은 밑줄이라 정상)
- [ ] 사람 이름은 한 번 더 봤다 — 문서 안에 두 번 이상 나오면 서로 맞춰 본다
- [ ] 손글씨에서 `[?]`가 많으면 가로 띠 네 조각으로 잘라 다시 읽혔다
- [ ] 따옴표로 인용할 문장은 `[?]`가 없는 문장에서만 골랐다
