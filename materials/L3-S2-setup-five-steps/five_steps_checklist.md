# 다섯 걸음 체크리스트

순서대로 하나씩, 전부 해도 1시간 안. 지금 다 하지 않아도 됩니다 — 내 자리를 표시하고 다음 한 걸음만 고릅니다.

## 시작 전에 세 줄

- [ ] 환자 정보 · 실명 명단 · 성적 · 보안 구역 정보는 입력창에 넣지 않는다. 규칙보다 손이 먼저.
- [ ] 개인정보 파일은 한 폴더에 몰아넣고 「이 폴더는 읽지 마」라고 지시한다(필요하면 폴더 암호도).
- [ ] 발행 · 발송 · 삭제는 반드시 내가 최종 확인한다. 도장은 사람이 찍는다.

## 다섯 걸음

| 된 것 | 걸음 | 하는 일 | 여기까지 됐으면 화면에 이게 보입니다 |
|---|---|---|---|
| [ ] | ① 결제 | claude.ai 접속 → 로그인 → 요금제 선택. 가장 싼 유료 요금제는 맛보기 수준이라 금방 한도에 막힌다 → 그 위 요금제로 시작. *(요금제 이름·금액·한도는 작성 시점 기준 — 결제 화면에서 다시 확인)* | 결제가 끝난 계정으로 로그인돼 있다 |
| [ ] | ② 설치 | 클로드 데스크톱 앱 설치(`claude.ai/download`). 열 때 코워크 방식이 아니라 **코드 방식**으로. 터미널 · 웹 미리보기 · 작업 모니터링이 그 안에 들어 있다. | 코드 방식 화면이 열려 있다 |
| [ ] | ③ 첫 설정 | 호칭 정하기(「나를 ___라고 불러줘」) · 개인정보 · 동의 항목 확인 · 모델은 기본값으로 시작. | 정한 호칭으로 불린다 |
| [ ] | ④ 파일 한 장 (20분) | 폴더 하나 만들기(예: `내AI작업실`) → 양식 파일을 넣고 이름을 `CLAUDE.md` 로 → 빈칸 채우기(나는 누구인가 · 일하는 원칙 · 넘지 말아야 할 선 · 말투 — 내가 이미 써 둔 자기소개 · 원칙 메모를 옮겨도 된다) → 코드 방식에서 **그 폴더를 작업 폴더로 지정**. | 작업 폴더가 잡혀 있다 |
| [ ] | ⑤ 말 걸기 | 첫 대화는 **계획 모드**로. (선택) 음성 입력 도구로 타이핑 대신 말로 — 말이 엉켜도 논리는 AI가 세운다. | AI가 일을 벌이기 전에 나에게 질문을 먼저 한다 |

## 내 자리

- 지금 된 걸음: ① ② ③ ④ ⑤ (동그라미)
- 다음 한 걸음(맨 앞 하나만): ______________________
- 언제 할지: ______________________

## 막혔을 때

멈추고, AI에게 이렇게 보낸다 → 나온 글을 질문 칸에 붙인다.

```text
내가 지금 뭐가 안 되고 있는지 설명하고, 질문하려고 해. 메시지를 작성해줘.
```

「안 돼요」보다 「이 단계에서 이 메시지가 떴어요」가 훨씬 빨리 풀린다.
