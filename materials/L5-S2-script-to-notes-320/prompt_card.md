# 원고 나누기 지시문 카드

강의 원고 한 편을 슬라이드별 읽을 대본으로 나누고, 분량을 분으로 환산하게 하는 지시문입니다. 브라우저의 AI 대화창에 원고·슬라이드 목록과 함께 붙입니다.

## 1. 기본 — 그대로 복사

```text
아래 원고를 슬라이드 목록에 맞춰 나눠 주세요. 원고 문장은 고치거나 줄이지 말고 그대로 옮기고, 슬라이드마다 「## 슬라이드 N — 제목」으로 시작해 주세요. 배경 설명이나 말하는 법 조언은 넣지 마세요. 실제 동작(예: (30초 침묵))만 괄호로 남겨 주세요. 끝에 표를 붙여 슬라이드마다 한글 글자 수(가~힣만 — 띄어쓰기·숫자·영문·문장부호 제외), 그 수를 320으로 나눈 분, 누적 분을 적고, 맨 아래에 원고 전체 한글 글자 수와 메모 합계 한글 글자 수를 나란히 적어 주세요.
```

붙이는 순서: 이 지시문 → 슬라이드 목록 → 원고.

## 2. 메모가 줄어 돌아왔을 때

메모 합계가 원고의 95%보다 적으면 보냅니다.

```text
원고 문장을 줄이거나 바꾸지 말고, 빠진 문장 없이 원고 그대로 다시 나눠 주세요. 설명이나 조언 문장은 모두 빼 주세요.
```

## 3. 셈법 — 무엇을 세고 무엇을 빼나

| 센다 | 세지 않는다 |
|---|---|
| 한글 음절(가~힣) | 띄어쓰기 · 숫자 · 영문 · 문장부호 |
| 소리 내어 읽는 인용문 | 읽지 않는 안내 줄 |
| 슬라이드 본문 | 「## 슬라이드 N — 제목」 머리 줄 |

- 분 = 한글 글자 수 ÷ 320. 50분이면 16,000자쯤이다.
- 320은 어림이다. 침묵 같은 실제 동작의 시간은 글자 셈에 없으니 따로 더한다.

## 4. 받은 메모 점검

- [ ] 모든 슬라이드에 메모가 있다.
- [ ] 슬라이드 번호와 제목이 내 목록과 같다.
- [ ] 원고에 없던 문장(설명·조언·「여기서는 천천히」 같은 말)이 없다.
- [ ] 메모 합계 한글 글자 수가 원고의 95% 이상이다.
- [ ] 괄호 안에 남은 것은 실제 동작과 당일에 채울 빈칸뿐이다.
