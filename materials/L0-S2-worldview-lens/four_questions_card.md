# 네 질문 카드

인쇄하거나 메모 앱에 옮겨 쓰는 한 장입니다. 설치는 필요 없습니다. 질문에 실명·환자 정보는 넣지 않습니다.

## 1. AI에게 물은 질문

```text
날짜: ____________
물은 질문: ________________________________________
```

예: 쉼 · 성공 · 오래 아픈 환자의 「왜 하필 나냐」

## 2. 네 질문 — 답에서 문장 하나씩

| 막 | 질문 | 답에서 옮긴 문장 (없으면 「대답 없음」) |
|---|---|---|
| 창조 | 무엇을 선하게 지어진 것으로 보는가 — 쓸모인가, 존재 자체인가 | |
| 타락 | 무엇이 잘못되었다고 보는가 — 뿌리를 어디에 두는가 | |
| 구속 | 무엇이 그것을 바로잡는다고 보는가 — 기술·노력뿐인가, 회복과 돌봄인가 | |
| 완성 | 결국 어디로 간다고 보는가 — 좋은 삶의 끝을 무엇으로 그리는가 | |

진료실 질문이었다면 한 칸 더:

| 고통을 | ☐ 지워야 할 문제로만 다룬다 · ☐ 의미를 묻는 자리로도 대한다 |
|---|---|

## 3. 나의 쓰임에 돌리기

| 질문 | 한 줄 |
|---|---|
| 나는 왜 이 질문을 AI에게 물었나 | |
| 나는 이 도구를 구원자처럼 기대고 있지는 않은가 | |

## 4. 평가 한 단락

```text
① 이 답이 잘 본 것:
② 걸리는 질문 하나와 그 까닭:
③ 대답하지 않은 질문:
④ 나의 쓰임에 돌리는 한 문장:
```

규칙: 첫 문장은 「잘 본 것」으로 · 판정이 아니라 도수 재기 · 네 칸을 다 못 채워도 단락이 있으면 끝.
