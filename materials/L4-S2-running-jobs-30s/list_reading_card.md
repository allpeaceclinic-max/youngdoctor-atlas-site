# 목록 읽기 카드 (맥)

읽기만 하는 명령이다. 설치·관리자 권한 없이 친다.

```bash
launchctl list                       # 전체 (세 열)
launchctl list | grep -v com.apple   # 운영체제 것 빼고
launchctl list | grep application.   # 지금 열린 앱 줄만
```

## 세 열

| 열 | `-` 또는 `0` | 숫자 |
|---|---|---|
| 1열 PID | `-` = 지금은 떠 있지 않다 | 지금 떠 있다 |
| 2열 Status | `0` = 마지막에 오류 없이 끝났다 | 음수 = 신호로 멈췄다 · 그 밖 = 마지막에 실패(뜻은 그 프로그램이 정한다) |
| 3열 Label | — | 앞머리로 누구 것인지 가른다 |

## 앞머리

- [ ] `com.apple.` — 운영체제. 건드리지 않는다
- [ ] `application.` — 지금 열어 둔 앱
- [ ] 앱 만든 곳의 이름 — 앱이 건 예약 작업(업데이터 등)
- [ ] 내가 정한 앞머리 — 내가 건 것 (아직 0줄이면 정상)

## 기억할 두 줄

- 2열 숫자는 **어느 잡을 볼지**를 가리킬 뿐, **왜** 멈췄는지는 말해 주지 않는다.
- 2열 `0`은 「오류 없이 끝났다」일 뿐 「일을 했다」가 아니다 — 산출물 날짜를 함께 본다.
