지도L3-S5

3층 도구 × ⑤ 바이브 코딩 제작자

AI에게 나를 어떻게 알려주고 일을 어떻게 시키나

칸 안의 순서 실전 6단계 — 3분할 → 병목 5신호 → 흐름 7칸 → 과제 문장 → 가장 작게 → 측정·검증

  1. 스킬 — 반복을 포장하고 플러그인으로 묶는다만들 예정 — 두 번 반복한 일을 스킬 한 개로 포장하고(개발 → 패키징 → 설치 → 기록), 쌓인 스킬을 플러그인 하나로 묶어 버전·변경 기록·함정 문서를 어디에 두는지 정한다.
  2. 설정 3층·허용 목록·훅 — Claude Code를 내 작업에 맞춘다만들 예정 — 전역·전역 로컬·프로젝트 설정 3층에 무엇을 두는지, 허용 목록이 「실제로 자주 쓴 도구」를 어떻게 보여 주는지, 세션의 시작·중간·끝에 끼어드는 훅을 어떻게 거는지 익힌다 — 막기보다 되돌리기를 먼저 둔다.
  3. MCP 서버 세 출처와 로컬·원격의 차이만들 예정 — 내 세션에 보이는 도구가 사용자 설정·플러그인·계정 커넥터 중 어디서 왔는지 가르고, 로컬(stdio)과 원격(HTTP) 서버의 프라이버시·수명 차이와 같은 서버를 두 곳에 등록했을 때의 혼선을 안다.
  4. 외부 서비스 CLI를 한 벌로 — 래퍼·홈 분리·버전 고정만들 예정 — 여러 경로로 깔린 외부 CLI를 래퍼 하나로 일원화하고 홈·버전을 고정해 조용히 두 벌이 되는 사고를 막으며, 증상(재로그인)과 원인(회전 안 함)을 저장소 파일의 시각으로 가르고 은퇴한 도구도 문서에 남긴다.

이 칸에 걸치는 노드

  • 과제 문장과 숫자 하나 — baseline 심기만들 예정
  • 하네스 — AI가 일하는 틀과 지침 파일만들 예정
  • 받은 스킬 설치 → 수정 → 내 스킬만들 예정
  • 커넥트와 API — 손이 닿는 범위만들 예정
  • AI에게 브라우저를 맡기는 네 길과 금지선만들 예정
  • 로그인은 사람이, 그 뒤는 AI가만들 예정
  • 에이전트 — 일을 맡기는 단위만들 예정
  • 스킬 단일 진실원 — 같은 파일이 다섯 벌이 되는 과정만들 예정
