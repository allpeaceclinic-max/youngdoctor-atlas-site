지도L4-S3

4층 자동화·운영 (launchd / 작업 스케줄러) × ③ 업무 진단자

매일 저절로 돌게 하고, 죽은 것을 어떻게 아나

칸 안의 순서 실전 6단계 — 3분할 → 병목 5신호 → 흐름 7칸 → 과제 문장 → 가장 작게 → 측정·검증

  1. 폴더에 넣으면 처리된다 — 가장 쉬운 반자동 입구만들 예정 — 내 업무 흐름에서 「받아서 옮기는」 반복 칸을 골라, 지정 폴더에 파일을 떨어뜨리면 2분 안에 처리되는 입구를 설계한다 — 쓰기 완료 대기·해시로 중복 막기·processed와 failed 폴더가 설계의 전부다.
  2. 모든 잡의 출구는 하나 — 「나에게 보내기」 알림 통로와 알림 피로만들 예정 — 자동화마다 알림 방식을 따로 만들지 않고, 메신저 「나에게 보내기」 하나(1회 인증·두 달마다 재인증·200자 상한)를 모든 잡의 공통 출구로 두되, 「평소 매일 오던 것이 끊길 때만」 울리는 규칙으로 알림 피로를 막는다.
  3. 내 컴퓨터가 꺼져 있어도 도는 잡 — 서버 cron 한 줄로 아침 일정 요약만들 예정 — 맥이든 윈도우든 내 컴퓨터에 의존하지 않는 가장 작은 자동화로, 데이터베이스의 예약 기능이 매일 아침 함수 하나를 깨워 오늘 일정·마감을 요약해 메신저로 보내는 구조를 따라 만든다 — 외부 캘린더와의 동기화는 증분 토큰과 충돌 규칙이 핵심이다.

이 칸에 걸치는 노드

  • ▶내 컴퓨터에서 이미 저절로 도는 것들 — 30초 목록 읽기
  • ▶매일 아침 저절로 오는 묵상 메모 한 통 — 첫 자동화는 AI 없이
  • 기록되지 않은 세션은 끝난 게 아니다 — BOOT·WRITE-BACK 규약과 세션 훅만들 예정
